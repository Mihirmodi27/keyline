# Brief: account settings

Build the account settings page for **Northwind**, a project-management app.

It needs a profile section (photo, full name, email, job title, time zone), notification preferences (email and push toggles for mentions, comments, task assignments and a weekly summary), a password change form, connected accounts (Google, GitHub, Slack, each connected or not), and a danger zone where the user can delete their account. Include save buttons and some form validation states, for example an invalid email.

Make it look modern and polished.
