# Brief: analytics dashboard

Build the main dashboard page for **Lumen**, a product-analytics tool for small SaaS teams.

It should have a sidebar with navigation (Overview, Events, Funnels, Retention, Users, Settings) and the workspace name, a header with the page title, a date-range picker and a search, four headline metrics (visitors, sign-ups, conversion rate, revenue) with their change from the previous period, a chart of daily visitors over the last 30 days, a table of the top pages (path, views, unique visitors, average time, bounce rate), and a feed of recent activity.

Make it look modern and polished.
